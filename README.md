## Omilia Natural Numbers Interpretation

This project provides and simple solution for the task of interpreting natural numbers in phone numbers, by Omilia.
This is not intended to be a comprehensive solution for all phone number formats, this is just a solution for a specific test case.

## Quick Start

To get started with this project, you can install the required dependencies and run the provided tests.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/omilia-natural-numbers-interpretation.git
   cd omilia-natural-numbers-interpretation
   ```

2. Install uv:
   ```bash
    pip install uv
   ```

3. Run the streamlit application:
   ```bash
   uv run streamlit run app.py
   ```

### Running Tests

To run the tests, use the following command:
```bash
cd omilia-natural-numbers-interpretation
uv run pytest tests
```
